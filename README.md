# G1R MCP

Подпроект моста MCP для Gothic 1 Remake на основе официального Modkit / AngelScript. Пользователь выбрал эту основу 30.10.2026 для работы с новым обновлением игры.

## Рабочая база

`G1R MCP/` — основной рабочий каталог этого моста: документация и исходники, инструменты и проверки принадлежат подпроекту. Здесь инициализирован собственный Git; каталог целиком исключён из родительского репозитория `G1R Mods` через `/G1R MCP/`. Это самостоятельный локальный репозиторий, не Git-подмодуль. Удалённый репозиторий не настроен.

Правила родительского проекта: [AGENTS.md](../AGENTS.md). Локальные источники исследования расположены вне подпроекта и не включаются в его историю.

## Быстрое подключение к игре

Игра запускается через Steam. Для уже открытого главного меню:

```powershell
.\tools\build_native.ps1
.\tools\load_native.ps1
.venv\Scripts\python.exe -B tools\probe_native_route.py --enable --call-verified-as
```

Сборка загруженной DLL невозможна, пока игра удерживает файл: сначала штатно закрыть игру, собрать DLL, затем запустить игру через [start_g1r_development.ps1](tools/start_g1r_development.ps1). Скрипт загрузки не меняет игровые файлы; библиотека остаётся в `build/native/Release/`. `--enable` устанавливает очередь Tick, `--call-verified-as` выполняет один проверенный вызов без игровых изменений.

[Команды, MCP-конфигурация и ограничения нативного маршрута](docs/mods/G1R_MCP/native-route.md).

## Запуск MCP-сервера

Для всех чатов Codex настроен один общий сервер `http://127.0.0.1:27124/mcp`.

```powershell
uv sync --locked
.\tools\start_shared_mcp.ps1 -Json
```

Повторный запуск сохраняет процесс. Постоянная Windows-пара (Python-сервер и загрузчик `.venv`) общая для всех чатов; новый чат не добавляет процессов. Старые stdio-экземпляры остановлены. Уже открытые Codex-сессии обновить новой сессией или перезапуском приложения. После перезагрузки Windows сервер запускается указанной командой. Подробные настройки, ограничения совместной работы и остановка описаны в [нативном маршруте](docs/mods/G1R_MCP/native-route.md).

Для отдельного stdio-клиента сохранён прежний режим:

Из корня подпроекта после установки `uv` и Python:

```powershell
uv sync --locked
.venv\Scripts\python.exe -B -m g1r_mcp.server `
  --modkit-root '..\G1R-Modkit' `
  --workspace-root '.' `
  --source-revision 619c2e6d6cc908678c20d63fd4965156b2cbbca9
```

Сервер ожидает MCP-сообщения на stdio. Клиент запускает его как дочерний процесс; запуск сервера не запускает игру. Корни источников и пакетов задаются явно, абсолютные игровые пути в runtime-коде не зашиты. `--source-revision` — метка выбранного источника, а не автоматическая Git-проверка каждого чтения.

Python **3.11+**, официальный SDK **mcp 2.3.0**; проверено Python 3.14.6. `uv.lock` фиксирует зависимости. Python packaging нормализует техническую версию до `1.0.0.dev14`; код, документация и коммит используют проектный формат `1.0.0-dev.14`.

Подробный контракт: [локальные инструменты](docs/mods/G1R_MCP/local-tools.md), [нативные инструменты](docs/mods/G1R_MCP/native-route.md).
