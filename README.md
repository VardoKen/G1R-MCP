# G1R MCP

Подпроект моста MCP для Gothic 1 Remake на основе официального Modkit / AngelScript. Пользователь выбрал эту основу 30.10.2026 для работы с новым обновлением игры.

## Рабочая база

`G1R MCP/` — основной рабочий каталог этого моста: документация и будущие исходники, инструменты и проверки принадлежат подпроекту. Здесь инициализирован собственный Git; каталог целиком исключён из родительского репозитория `G1R Mods` через `/G1R MCP/`. Это самостоятельный локальный репозиторий, не Git-подмодуль. Удалённый репозиторий не настроен.

Правила родительского проекта: [AGENTS.md](../AGENTS.md). Локальные источники исследования расположены вне подпроекта и не включаются в его историю.

## Текущее состояние на 30.10.2026

- Созданы рабочий каталог, самостоятельный Git и начальная документация.
- Пользователь поручил начать PLAN-001; целевая публичная версия **1.0.0**, назначение — полноценный инструмент разработки модов для ИИ-агентов через MCP.
- Начаты Э0–Э1: установленная Steam public build **26295476**, все **7 280** файлов `Script/*.as` совпадают с официальным Modkit ревизии `619c2e6d6cc908678c20d63fd4965156b2cbbca9`.
- Созданы воспроизводимые диагностические инструменты среды, AngelScript-протокола и запуска через Steam; **27 автономных тестов прошли**.
- Канал связи не доказан. В проверенном Steam-запуске с `-FromModManagementUI` и параметрами разработки TCP-listener не появился. Alkimia [подтвердила отсутствие LSP в 1.1 и его включение в следующем обновлении](https://github.com/AlkimiaInteractive/G1R-Modkit/issues/1#issuecomment-6520702135). Фактическая активация пользовательских модов по командной строке не устанавливается.
- Реализован внешний stdio MCP-сервер **1.0.0-dev.1** с семью локальными инструментами: статус, возможности, поиск и чтение исходников, лексический поиск типов и структурная проверка официальных пакетов. Это первый рабочий код; версия техническая, полного выпуска 1.0.0 ещё нет.
- Игровой мод, игровой канал, наблюдения, действия и runtime-компиляция пока не реализованы. Сервер явно сообщает их недоступность; локальные инструменты работают независимо от игры.
- [Активный PLAN-001](docs/mods/G1R_MCP/plans/PLAN-001-active-implementation.md) актуализирован до **R3**: независимая часть Э4 реализуется, Э1 ожидает пригодного официального канала. Полноценный инструмент ещё не готов.

## Запуск MCP-сервера

Из корня подпроекта после установки `uv` и Python:

```powershell
uv sync --locked
.venv\Scripts\python.exe -B -m g1r_mcp.server `
  --modkit-root '..\G1R-Modkit' `
  --workspace-root '.' `
  --source-revision 619c2e6d6cc908678c20d63fd4965156b2cbbca9
```

Сервер ожидает MCP-сообщения на stdio. Клиент запускает его как дочерний процесс; запуск сервера не запускает игру. Корни источников и пакетов задаются явно, абсолютные игровые пути в runtime-коде не зашиты. `--source-revision` — метка выбранного источника, а не автоматическая Git-проверка каждого чтения.

Python **3.11+**, официальный SDK **mcp 2.3.0**; проверено Python 3.14.6. `uv.lock` фиксирует зависимости. Python packaging нормализует техническую версию до `1.0.0.dev1`; код, документация и коммит используют проектный формат `1.0.0-dev.1`.

Подробный контракт и границы: [локальные инструменты dev.1](docs/mods/G1R_MCP/local-tools.md).
