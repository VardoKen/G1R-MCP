# Проверки подпроекта G1R MCP

Общие правила проверок — в [документации проекта](../../../docs/tests/README.md). Набор G1R MCP и подробные источники результатов — в [индексе проверок](G1R_MCP/README.md).

Инструмент предназначен для исследования API и состояния игры, разработки и отладки официальных модов. Возможность переносить моды с UE4SS — промежуточный рубеж; сами переносы и публичная поставка не объявляются результатом этого тестового прогона.

**Локально проверено dev.99:** 736/736 Python-тестов за 484,948 с, failures/errors/skips — 0; из 737 обнаруженных один helper-case исключён из-за сохранённого dirty manifest и отдельно прошёл 1/1 на Git-версии. CTest — 39/39 за 7,99 с. Общий HTTP-сервер dev.99 и установленный wheel dev.99 с внешним `--runtime-root` приняты; consumer-проба выполнила шесть вызовов и получила 51 инструмент без запуска игры.

**Игровые подтверждения исторические:** выбранные операции и нагрузка проверены в сериях dev.95–96. Их результаты относятся к указанным DLL, пакетам и сценариям. DLL dev.99 в локальной consumer/shared-приёмке не загружалась и новой игровой приёмкой не подтверждена.

**Пределы:** установленный wheel использует отдельный runtime-комплект DLL/loader/PowerShell. Официальный helper-пакет не доказывает автоматическую загрузку DLL из Steam. Публичные публикации Steam/PyPI, все игровые API и полный будущий релиз этими проверками не объявляются готовыми. Подробные источники, прежние неуспешные прогоны и границы подтверждения сохранены в [индексе набора](G1R_MCP/README.md).
