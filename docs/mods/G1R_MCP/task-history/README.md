# История задач G1R MCP

## 30.10.2026 — подробный активный план реализации

По прямому поручению пользователя подготовлен [PLAN-001](../plans/PLAN-001-active-implementation.md), редакция R1: зависимые этапы Э0–Э9, критерии завершения, исследовательские развилки и способ актуализации по результатам. Созданы активный индекс, единый реестр, пустые индексы отложенных планов и архива; обновлены навигация и проверенные источники.

Источник проверки: существующие документы подпроекта, локальный официальный Modkit и контракты MCP to UE4SS; проверены UTF-8, ссылки, итоговый diff и синхронизация реестров. Отложенных изменений G1R MCP нет; реестр прежнего Lua Bridge также не содержал текущих отложенных изменений. Разработка, прототипы и игровые проверки не начинались; целевая версия не назначена.

## 30.10.2026 — создание самостоятельного подпроекта

По прямому поручению пользователя создан каталог `G1R MCP/` с собственным Git. Родительский репозиторий исключает этот каталог через `/G1R MCP/` и содержит ссылку в индексе документации. Подготовлены [назначение и архитектурные предложения](../README.md), [реестр источников](../references/README.md) и корневой вход в подпроект.

Источник проверки: состояние файлов, разрешение локальных ссылок, `git rev-parse`, `git check-ignore`, `git status` и просмотр итоговых изменений в обоих репозиториях. Отдельные начальный коммит подпроекта и коммит исключения в основном репозитории фиксируют эту задачу в собственных историях Git.

Код мода и сервера не создавался; архитектурные предложения и канал связи не утверждены. Игровая среда не использовалась, номер версии не назначен.
